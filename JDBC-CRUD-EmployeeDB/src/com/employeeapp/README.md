# 🧾 Employee Database Mini Project (JDBC + MySQL)

A simple console-based Java application that performs **CRUD (Create, Read, Update, Delete)** operations using **JDBC** and **MySQL**.

---

## ⚙️ Tech Stack
- Java (JDK 17 or above)
- MySQL
- JDBC Driver (mysql-connector-j)
- IDE: Eclipse / IntelliJ / VS Code
